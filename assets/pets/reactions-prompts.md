# 동물 반응 이미지 제작 기록

Built-in image_gen 사용. 각 동물의 기존 PNG를 참조한 투명 배경 2×2 이미지 시트.
대상: panda, capybara, tiger, penguin.

프롬프트: 기존 동물의 정체성과 따뜻한 수채화 질감을 유지한다. 정사각형을 2×2 동일 크기 셀로 구성한다. 왼쪽 위는 식사를 마치고 배를 만지며 만족하는 모습과 빈 그릇, 오른쪽 위는 공놀이 후 지쳐 옆으로 누운 모습과 작은 공, 왼쪽 아래는 눈을 감고 웅크려 자는 모습, 오른쪽 아래는 쓰다듬어져 눈을 감고 행복해하며 작은 하트가 떠 있는 모습. 전신이 각 셀 안에 완전히 들어가고 셀 사이에 투명 여백을 둔다. 배경·격자·글자·사람·손을 넣지 않는다.

호랑이 추가 수정: 네 자세와 소품·배치를 유지하고 흰 종이 배경과 흐린 광채를 모두 제거하여 실제 투명 배경으로 만든다. 동물 내부의 흰 털은 유지한다.
