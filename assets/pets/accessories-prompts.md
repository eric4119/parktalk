# 액세서리 이미지 제작 기록

Built-in image_gen 사용. 기존 판다 PNG를 수채화 스타일 참조로만 사용하고, 각 물건을 투명 배경 단일 이미지로 제작.

- hat-v2.png: 부드러운 버터 노란색 베레모, 둥근 형태, 섬세한 바느질 선, 따뜻한 호박색 테두리, 정면, 다른 물체 없음.
- glasses-v2.png: 둥근 투명 렌즈 두 개와 얇은 갈색 안경테, 짧게 굽은 다리, 정면, 대칭, 다른 물체 없음.
- necklace-v2.png: 얕은 U자 형태의 갈색 목걸이 줄과 중앙의 작은 황금 별 장식, 정면, 다른 물체 없음.

공통 제약: 정사각형 화면 중앙에 물건 하나만 배치하고 넉넉한 투명 여백을 둔다. 기존 동물과 어울리는 따뜻한 손그림 수채화 질감을 유지한다. 동물·글자·흰 배경을 포함하지 않는다.
